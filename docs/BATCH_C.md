# AI privacy and spending controls

Prepared 2026-11-23 from [EDGE-01 through EDGE-07 and GRT-01](DB_AUDIT.md). No live project, provider, or production data was accessed.

| Audit ID | Change |
|---|---|
| EDGE-02 and EDGE-04 | Home builds Today’s brief from the existing care and request data. It shows counts for due and overdue doses, overdue tasks, low or out-of-stock items, open shifts starting in the next 48 hours, and incoming and outgoing pending join requests. Refresh reloads the data. The card keeps its layout and IDs, and the AI footer is absent from the rendered card. The retired `home-digest` function returns 410 and the `home_digests` table is retained. |
| EDGE-01 | Handoff and saved summaries require both deployment enablement and per-circle owner opt-in. Each send starts with a browser preview that shows the note count, dates, 80-character excerpts, and expandable full text. Cancellation makes no Edge Function call. |
| EDGE-03 and EDGE-05 | The server enforces a 16 KiB streaming request limit before JSON parsing. A reservation is committed before making one Gemini request, with no automatic retries and a 400-output-token cap. A failed generation still consumes its reservation. Cooldown is 60 seconds per circle, and the daily cap is 10 per user across circles on the Manila calendar day. |
| GRT-01 | The Edge Function verifies the caller with `auth.getUser()` and uses that caller’s RLS client to confirm membership and preview content. New `ai_log` drafts are written by a separate function-only service-role client. Members retain read access. Existing entries remain available as unverified history. Add note still writes to `care_notes`. |
| EDGE-06 and EDGE-07 | CORS echoes only configured origins. Gemini failures, rate limits and timeouts get fixed codes and safe text. The output filter rejects apparent medication or dose instructions without saving them. Drafts remain visibly labeled “AI-generated draft. Not medical advice.” |

The browser and Edge Function use the same minimizer. At most 20 recent notes are included, each limited to 300 characters. The preview drops older notes if needed to fit the byte limit. Gemini receives date-only Manila dates and minimized text plus a fixed task prompt. The request to Gemini has no author IDs, author fields, circle name field, or circle ID. The minimizer removes email and phone-like patterns and recognized circle and current-member display names in note text. It cannot recognize every identifier in free text, including alternate names and references to former members. Review the full text before sending. Medicine names and other care details can remain in that text.

The server rebuilds the minimized preview under the caller’s RLS context and refuses to send if it differs from the confirmed preview. The output filter is best-effort and can miss indirect instructions or reject benign text. Drafts are for human review. Consent changes block new reservations. An opt-out cannot retract a request sent while consent was active.

## Owner rollout

1. Retire the old deployed `home-digest` endpoint, or replace it with the included [410 endpoint](../supabase/functions/home-digest/index.ts). Disable the old handoff deployment or replace it with the new code while its deployment flag is unset. An old deployed function keeps its prior behavior until it is retired or replaced.
2. Apply the [Batch C migration](../supabase/migrations/20261123110000_batch_c_ai_privacy.sql) after Batches A and B. Deploy [handoff-brief](../supabase/functions/handoff-brief/index.ts) with its handler and shared minimizer, retaining gateway JWT verification. Publish the frontend with the [shared browser module](../supabase/functions/_shared/handoff-content.mjs) at the same relative path. Serve it as JavaScript. [Supabase Edge Function dependencies](https://supabase.com/docs/guides/functions/dependencies)
3. Configure the exact website origins in `ALLOWED_ORIGINS`. Check that `SUPABASE_URL`, `SUPABASE_ANON_KEY`, and `SUPABASE_SERVICE_ROLE_KEY` are available only as appropriate Edge runtime settings. Set `GEMINI_API_KEY` and `GEMINI_MODEL` only in the function environment when preparing approved testing. Never expose the service-role or Gemini key to the browser.
4. Keep `HANDOFF_BRIEF_ENABLED` unset and circle consent off until the venue, provider terms, data handling, and care-data consent have been approved. Validate using synthetic notes first. Google’s unpaid Gemini terms prohibit sending sensitive, confidential or personal information. When deployment enablement is appropriate, the circle owner must also use **Enable AI drafts** in that circle. [Gemini API terms](https://ai.google.dev/gemini-api/terms)
5. To roll back, disable the deployed AI endpoints first. The [manual SQL rollback](../supabase/migrations/manual/batch_c_rollback.sql) restores the Batch B insert policy and grants and drops consent, reservation history and provenance markers. It preserves the saved draft and digest rows. Coordinate the rollback with the frontend schema expectations.
